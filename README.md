# moviemind-mpcs1-ui

Dark, cinematic React + TypeScript + Tailwind UI for the MOVIEMIND MPCS-1 questionnaire (image gates + blank tarot text rounds).

## Binary Policy

- Raster binaries (png, jpg, jpeg, gif, webp, avif, psd, tif, tiff) must not be committed to this repository.
- Use inline data-URL placeholders or SVG assets within source files when visuals are required for development.
- When working locally with bespoke art, place those files in the same `/public/assets/...` directories but ensure they stay ignored (e.g., via `.gitignore`) and never reach the repo.
